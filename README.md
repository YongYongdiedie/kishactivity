# KISH 활동 둘러보기

검토된 「2026_학생활동목록(공유) 초안.xlsx」의 첫 번째 활동목록 시트에 있는 416개 활동을 사용하는 반응형 웹앱입니다. HTML·CSS·JavaScript만으로 실행되며 설치, 빌드, API 키, 외부 서비스 연결이 필요 없습니다.

## GitHub Pages로 배포

1. GitHub에서 새 저장소를 만듭니다. 예: `kish-activity-explorer`.
2. 압축을 해제한 **폴더 안의 파일들**을 저장소 최상위에 올립니다. `index.html`이 저장소 첫 화면에서 바로 보여야 합니다. ZIP 자체를 업로드하지 마세요.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment → Source → Deploy from a branch**를 선택합니다.
5. **Branch: main**, **폴더: / (root)**로 지정하고 **Save**를 누릅니다.
6. 배포가 끝나면 Pages 화면에서 제공되는 주소를 엽니다. 일반적인 주소는 `https://사용자명.github.io/저장소명/`입니다.

상대 경로를 사용하므로 저장소 이름을 바꿔도 동작합니다. `.nojekyll` 파일도 포함되어 있습니다. Pages 메뉴의 안내는 [GitHub 공식 문서](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)를 참고하세요. 저장소의 공개 범위·계정 정책에 따라 Pages 사용 가능 여부가 달라질 수 있습니다.

## 로컬에서 확인

`index.html`을 브라우저로 열면 기본 화면과 탐색이 실행됩니다. 바구니 저장을 포함해 배포 환경과 같은 방식으로 확인하려면 아래 명령으로 로컬 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 종료는 터미널에서 `Ctrl+C`입니다.

## 화면과 기능

- **관심 분야로 찾기**: 주분야·연관분야를 합친 20개 분야를 복수 선택합니다. 하나라도 연결된 활동을 중복 없이 보여줍니다.
- **활동부터 골라보기**: 가나다·ABC순 목록과 검색을 제공합니다.
- **전체 목록 둘러보기**: 검색어, 대범주, 진행 시기, 활동방식을 동시에 적용합니다.
- **활동바구니**: 리스트·원그래프·마인드맵 보기, 개별 삭제, 전체 비우기, 텍스트 계획 내려받기를 제공합니다.
- 활동명 또는 ‘자세히’를 누르면 관련 분야, 원자료의 일정, 담당 부서와 분류메모를 확인할 수 있습니다.
- 각 탐색 화면의 체크 상태는 탭을 바꿔도 유지됩니다. 오른쪽 아래 버튼은 다른 탐색 화면에서 체크한 활동까지 모두 담습니다. ‘체크 해제’는 아직 담지 않은 체크 전체를 해제합니다.
- 목록은 처음 24개를 보여주며 ‘활동 더 보기’로 이어집니다. ‘현재 표시된 활동 선택’은 화면에 로드된 결과만 선택합니다.
- 바구니는 브라우저의 `localStorage`에 저장되며 같은 브라우저에서 새로고침 후에도 유지됩니다. 로그인·서버 저장·기기 간 동기화는 없습니다. 브라우저 데이터 삭제 시 바구니도 지워집니다. 저장이 차단된 환경에서는 현재 페이지에서만 유지되며 알림이 표시됩니다.
- 원그래프는 **주분야만 집계**합니다. 연관분야까지 더해 중복 계산하지 않습니다.
- 마인드맵은 바구니 → 주분야 → 활동으로 연결됩니다. 분야를 클릭하거나 선택 상자에서 바꾸면 해당 분야의 활동을 펼칩니다. 작은 화면에서는 지도 영역을 스크롤합니다. 활동을 클릭하면 연관분야를 볼 수 있습니다.

## 데이터와 일정 처리

- 원자료의 활동명, 범주, 분야, 방식, 담당 부서, 근거 쪽수, 메모를 그대로 사용합니다. 상세 소개나 사진을 새로 만들어 넣지 않았습니다.
- 엑셀 숫자로 저장된 두 날짜 값은 날짜로 변환하여 `2027년 1월`로 표시했습니다.
- 월별 필터는 명시된 월, 월 범위, 월 나열을 읽습니다. 연중·상시 활동은 모든 월에 포함합니다. 수시·학기 중은 월을 임의 배정하지 않으며 ‘상시·연중·수시’ 필터에서 찾을 수 있습니다.
- 학기나 방학만 있고 월이 없는 활동은 ‘월 미정·미명시’에 포함합니다. 서로 다른 일정이 함께 기록된 활동은 원문을 그대로 보여주며 관련 월을 모두 검색합니다.
- 분류는 활동 탐색용입니다. 직업 예측·진로 적합도 평가·참여 신청 기능은 없습니다.

## 엑셀 수정 후 데이터 갱신

Python 3가 있으면 외부 패키지 설치 없이 갱신할 수 있습니다.

```bash
python3 tools/import_xlsx.py "/파일경로/수정된_학생활동목록.xlsx"
```

`학생활동목록`이라는 시트를 읽으며 시트명 앞뒤 공백은 무시합니다. 첫 행에 `활동명`, `대범주`, `예상 진행시기`, `주분야`, `연관분야`, `활동방식` 헤더가 있어야 합니다. 연관분야와 활동방식의 복수 값은 `/`로 구분합니다. 변경된 `data.js`를 GitHub에 다시 올리면 됩니다.

활동 ID는 활동명과 주관부서로 만들므로 행 순서만 바꾸면 기존 바구니가 유지됩니다. 활동명이나 주관부서를 바꾸거나 활동을 삭제하면 기존에 담긴 해당 활동은 더 이상 연결되지 않습니다. 개인정보나 원본 엑셀은 업로드할 필요가 없습니다. 배포된 `data.js` 내용은 웹 방문자에게 공개됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 첫 화면과 공통 구조 |
| `styles.css` | 모바일·데스크톱 화면 디자인 |
| `app.js` | 화면, 선택, 저장, 시각화 |
| `core.js` | 검색·필터·분야 집계 |
| `data.js` | 검토한 416개 활동 |
| `favicon.svg` | 앱 아이콘 |
| `tools/import_xlsx.py` | 엑셀을 활동 데이터로 변환 |
| `tests/core.test.cjs` | 데이터·검색·일정·집계 검증 |

## 검증 명령

Node.js 18 이상에서 실행합니다. 런타임 배포에는 Node.js가 필요하지 않습니다.

```bash
node --test tests/core.test.cjs
```

화면을 수정한 뒤에는 관심 분야 선택 → 활동 체크 → 바구니 담기 → 새로고침 → 세 가지 보기 전환 → 삭제를 확인하세요. 스마트폰 화면에서 필터, 상세 창, 하단 담기 버튼도 함께 확인하면 됩니다.
